    How the live sync is set up
    1. In each terminal, add your database URL under Tools › Options › Expert Advisors › Allow WebRequest for listed URL.
    2. Put PortfolioPush in MQL4\Experts or MQL5\Experts, compile it, and attach it to one chart per terminal with the URL and key in its inputs. It only reads your account; it never trades.
    3. The EA sends every deal, deposit and equity low within 30 seconds, resends anything that failed, and the database skips duplicates, so nothing is lost or double counted.
    4. This page reads the database through your Supabase connection when it opens and every 5 minutes. On MT4, set the Account History tab to All History once so the full history goes up.
